## Who Should Use This Documentation?

This documentation is designed for distinct audiences:

### 📊 Economists & Data Practitioners

If you need to **access World Bank's estimates**, such as [poverty and inequality estimates](https://pip.worldbank.org) or other indicators, this documentation will show you:

- How to search for specific indicators
- What data is available and at what granularity
- How to filter data by country, year and other dimensions
- Practical data retrieval examples

**Start with**: [Available Data](2-guides/1-practitioners/available-data.md) or [Searching for Indicators](2-guides/1-practitioners/searching-indicators.ipynb)

### 💻 AI Developers

If you are **integrating this MCP server** into AI applications, chatbots, or other systems, you will find:

- Setup and integration instructions
- Error handling and best practices
- Examples of adding Data360 MCP to Claude, ChatGPT or other applications

**Start with**: [Development Setup](2-guides/2-developers/setup.md) or [Integration Guide](2-guides/2-developers/integration.ipynb)

### 🏗️ Contributors

If you need to **deploy and maintain** this MCP server in production, you will learn:

- Configuration and environment setup
- Monitoring, logging and troubleshooting

**Start with**: [Deployment Overview](2-guides/3-deployment/deployment-overview.md)

If you want to **extend or maintain** the codebase, this documentation covers:

- Project architecture and structure
- Contributing guidelines

**Start with**: [Contributing Guide](4-development/CONTRIBUTING.md)
